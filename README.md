# matrix_tutorial
Simple implementation of matrices in C for educational purposes about C programming under Linux.

A matrix is defined as a C `struct` containing two insigned `integers` a `boolean` and a list of `scalar`s (doubles).

`n1` and `n2` define the number of lines and columns in the matrix. 

This project implements multiple different types of algebra for matrices :
* matrix creation
* matrix destruction (to not keep it's space in the memory)
* matrix addition 
* matrix multiplication (also by a scalar)
* matrix exponentiation

These functionnalities have been rigourously tested in the test_matrix file. 

To use this project please fork the repisitory online and then import the corresponding library.
